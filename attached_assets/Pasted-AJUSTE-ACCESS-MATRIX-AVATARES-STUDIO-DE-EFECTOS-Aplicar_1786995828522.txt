AJUSTE ACCESS MATRIX — AVATARES + STUDIO DE EFECTOS

Aplicar estas dos reglas sobre el sistema actual de permisos. No cambiar precios, créditos, límites de planes ni otras funciones.

1. AVATARES — USUARIO SIN PLAN

La página /avatars SÍ debe permanecer accesible para un role=user sin plan activo.

El objetivo es que pueda explorar lo que ofrece Reelsona y conservar acceso visual a sus recursos históricos.

Sin plan puede:

ver la biblioteca de Avatares públicos;
abrir/explorar los Avatares públicos;
ver sus Avatares AI históricos;
ver sus looks existentes;
ver que existe la función de clonación de voz.

Pero NO puede ejecutar ninguna acción premium.

Deben quedar bloqueadas:

seleccionar/usar un Avatar público;
crear Avatar AI personalizado;
crear un nuevo look;
clonar una voz;
seleccionar/configurar algo que genere costo;
generar contenido desde un avatar;
cualquier operación que consuma créditos o cree un nuevo recurso.

Cuando un usuario sin plan intente cualquiera de esas acciones, utilizar un único paywall reutilizable con exactamente este mensaje:

Función disponible con plan activo

Activa un plan de Reelsona para acceder a esta función. Tus proyectos y recursos siguen guardados.

CTA principal:

Ver planes

→ /billing

No abrir detrás del modal el flujo que el usuario intentaba ejecutar.

No llamar APIs que generen costo antes de comprobar el plan.

Backend debe mantener la protección con:

plan_required

y frontend debe convertir ese estado en el paywall, no mostrar un 403 técnico.

Caso especialmente importante: Avatar público.

La biblioteca debe cargar aunque el usuario no tenga plan.

Flujo esperado:

user sin plan
→ Avatares
→ ve biblioteca pública
→ selecciona un Avatar público
→ aparece:

Función disponible con plan activo

Activa un plan de Reelsona para acceder a esta función. Tus proyectos y recursos siguen guardados.

→ Ver planes
→ /billing

Exactamente el mismo comportamiento debe ocurrir con:

Crear Avatar AI

Crear look

Clonar voz

No crear mensajes diferentes para cada caso cuando la causa es la misma: ausencia de plan.
